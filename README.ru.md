Переписан на **Rust** по оригинальной программе «Furnica» (Ant v2.00, 1999),
которую используют в школах Молдовы и Румынии. Файлы `.ant` из старой версии
открываются и выполняются без изменений.

<img src="docs/assets/screenshot.png" alt="Furnica: пример «conferinta» после выполнения" />

## Быстрый старт

Готовые пакеты — на странице [Releases](../../releases):

```
furnica-<версия>-linux-x86_64.AppImage         # Linux, один файл
furnica-<версия>-linux-x86_64.deb              # Ubuntu / Debian / Mint
furnica-<версия>-linux-x86_64.tar.gz           # Linux, архив
furnica-<версия>-macos-universal.dmg           # macOS (Apple Silicon и Intel)
furnica-<версия>-windows-x64.msi               # Windows 10/11, 64 бита, установщик
furnica-<версия>-windows-x86.msi               # Windows 10/11, 32 бита, установщик
furnica-<версия>-windows-x64-portable.zip      # Windows 10/11, 64 бита
furnica-<версия>-windows-x86-portable.zip      # Windows 10/11, 32 бита
furnica-<версия>-windows7-x86-portable.zip     # Windows 7, 8, 10, 11 (32 и 64 бита)
SHA256SUMS.txt                                 # контрольные суммы
```

На каждой платформе:

- **Windows:** `.msi` устанавливает Furnica в *Program Files* с ярлыком в меню
  «Пуск», а файлы `.ant` открываются двойным щелчком (для многих компьютеров:
  `msiexec /i furnica-*.msi /qn`). Без установки: распакуйте zip и запустите
  `Furnica.exe`;
- **Linux:** сделайте AppImage исполняемым и запустите его
  (`chmod +x furnica-*.AppImage && ./furnica-*.AppImage`); в Ubuntu / Debian
  можно установить `.deb` (`sudo apt install ./furnica-*.deb`): Furnica
  появится в меню, а файлы `.ant` будут открываться двойным щелчком;
- **macOS:** откройте `.dmg` и перетащите `Furnica.app` на *Applications*.
  Приложение не подписано сертификатом Apple, поэтому при первом запуске:
  правый щелчок → *Открыть* (в macOS 15+: *Системные настройки →
  Конфиденциальность и безопасность → Всё равно открыть*), см. [macOS](#macos).

### Из исходного кода

Установите [Rust](https://rustup.rs), затем в этой папке:

```sh
cargo run --release                  # запустить приложение
cargo run --release -- program.ant   # сразу открыть файл
```

Исполняемый файл появится в `target/release/` (`furnica.exe` в Windows); его
можно копировать на другие компьютеры — других файлов ему не нужно. В Windows
значок муравья встраивается в `.exe` автоматически. Для вывода используется
OpenGL 2.0, чтобы программа работала и на старых компьютерах школьных классов.

## Что нового по сравнению с оригиналом

| | |
|---|---|
| **Интерфейс** | светлая и тёмная тема, новые логотип и значок; интерфейс на румынском, русском и английском |
| **Муравей** | векторный: чёткий при любом размере, плавно поворачивается и перебирает лапками на ходу |
| **Редактор** | нумерация строк, подсветка синтаксиса, кнопки для вставки команд (процедура вставляется перед `НАЧАЛО` автоматически), подсказки при наборе, автоотступ по Enter, форматирование |
| **Выполнение** | плавная анимация, подсветка текущей строки, путь муравья на таблице; по шагам, пауза, регулируемая скорость или мгновенно |
| **Анализатор** | программа проверяется во время набора, с предложениями исправлений ([подробнее](#анализатор-кода)) |
| **Блоки** | можно вкладывать как угодно (в оригинале `ПОВТОРИ` не мог содержать другой `ПОВТОРИ`, а `ПОКА` — другой `ПОКА`) |
| **Таблица** | редактируется прямо на ней, от 3 × 3 до 20 × 20 клеток ([подробнее](#редактирование-таблицы)) |
| **Файлы** | программа, таблица и настройки сохраняются между запусками; файлы открываются перетаскиванием или из командной строки |

### Редактирование таблицы

<img src="docs/assets/editare.png" alt="Ввод букв на таблице" />

- **муравья** перемещают перетаскиванием (клетка назначения подсвечивается
  зелёным или красным), а щелчок по нему поворачивает его;
- **буквы** вводятся с клавиатуры, как текст: щёлкните по клетке и печатайте,
  курсор сам переходит к следующей клетке (Backspace, Delete, стрелки, Enter,
  Esc);
- буквы перемещают перетаскиванием; брошенные на другую букву, они меняются с
  ней местами, а вытащенные за пределы таблицы (или по правому щелчку)
  удаляются;
- после выполнения начальная таблица не меняется; **Оставить результат**
  делает полученную таблицу новой начальной.

## Язык

Ключевые слова можно писать по-русски, по-румынски или по-английски (см.
[таблицу ниже](#ключевые-слова-на-трёх-языках)); здесь они на русском.

| Команда | Что делает |
|---|---|
| `ВВЕРХ`, `ВНИЗ`, `ВЛЕВО`, `ВПРАВО` | перемещает муравья на одну клетку; буква на пути сдвигается |
| `НАЧАЛО … КОНЕЦ` | основная программа |
| `ПОВТОРИ N РАЗ … КОНЕЦ ПОВТОРИ` | повторяет N раз |
| `ПОКА условие СДЕЛАЙ … КОНЕЦ ПОКА` | повторяет, пока условие истинно |
| `ЕСЛИ условие ТОГДА команда1 ИНАЧЕ команда2` | ветвление (`ИНАЧЕ` можно опустить) |
| `ПРОЦЕДУРА имя … КОНЕЦ ПРОЦЕДУРА` | определяет процедуру (перед `НАЧАЛО`) |
| `имя` | вызывает процедуру |
| `// …` | комментарий |

Условия: `КРАЙ` (муравей смотрит на край таблицы) и `НЕ_КРАЙ`. Муравей
смотрит в ту сторону, куда двигался в последний раз (в начале — в сторону,
сохранённую в файле; её меняет кнопка **Поворот**).

Муравей не может выйти за таблицу, не может вытолкнуть букву за край и не
может сдвинуть две буквы, стоящие одна за другой. В любом из этих случаев
программа останавливается с ошибкой, а место отмечается на таблице красным.

### Ключевые слова на трёх языках

Их можно писать на любом из языков, с диакритикой или без — это те самые
слова из файлов `romana.lng`, `engleza.lng` и `rusa.lng` оригинальной
программы.

| Română | English | Русский |
|---|---|---|
| `SUS JOS STÎNGA DREAPTA` | `UP DOWN LEFT RIGHT` | `ВВЕРХ ВНИЗ ВЛЕВО ВПРАВО` |
| `ÎNCEPUT SFÎRȘIT` | `BEGIN END` | `НАЧАЛО КОНЕЦ` |
| `REPETĂ ORI` | `REPEAT TIMES` | `ПОВТОРИ РАЗ` |
| `CÎT EXECUTĂ` | `WHILE DO` | `ПОКА СДЕЛАЙ` |
| `DACĂ ATUNCI ALTFEL` | `IF THEN ELSE` | `ЕСЛИ ТОГДА ИНАЧЕ` |
| `PROCEDURA` | `PROCEDURE` | `ПРОЦЕДУРА` |
| `E_MARGINE NU_E_MARGINE` | `BORDER NOT_BORDER` | `КРАЙ НЕ_КРАЙ` |

## Анализатор кода

<img src="docs/assets/analizor.png" alt="Анализатор кода с ошибками и подсказками" />

Программа анализируется при каждом изменении (это можно выключить в
*Настройках*; тогда анализ запускается кнопкой **Проверить** / F7). Анализатор
не останавливается на первой ошибке, а находит все:

- неверные слова подчёркиваются волнистой линией (красной — ошибка, жёлтой —
  предупреждение), а у номера строки появляется отметка; при наведении
  показывается объяснение;
- список **Проблемы** под редактором показывает все ошибки и предупреждения;
  щелчок переводит курсор к нужному слову;
- для слов с опечатками предлагается исправление («Возможно, вы имели в виду
  ВПРАВО?»), которое применяется кнопкой **Исправить** — и для имён процедур;
- программа с ошибками не запускается; предупреждения выполнению не мешают.

| Тип | Что обнаруживается |
|---|---|
| **Ошибки** | слова, которые не являются ни командами, ни процедурами; неизвестные условия; `ПОВТОРИ` без числа; незакрытые или неправильно закрытые блоки (`КОНЕЦ ПОКА` вместо `КОНЕЦ ПОВТОРИ`); лишние `КОНЕЦ`/`ИНАЧЕ`; нет команды после `ТОГДА`; нет `НАЧАЛО` или оно повторяется; процедуры, определённые дважды или внутри основной программы; текст после `КОНЕЦ` |
| **Предупреждения** | неиспользуемые процедуры; пустые блоки; `ПОВТОРИ 0 РАЗ`; циклы `ПОКА`, которые не двигают муравья (могут выполняться бесконечно); процедуры, вызывающие сами себя без остановки; пустая основная программа |

## Совместимость с оригиналом

Правила взяты из `furnica.exe` (Delphi 3): из форм в ресурсах и машинного кода
команд (старая программа не запускалась). С этими правилами оригинальные
примеры составляют ровно те слова, которые задуманы: «conferinta» и «svi99» в
первой строке (это проверяется тестами).

Решения, принятые там, где старое поведение было ошибочным или не
документированным:

- **`КРАЙ` влево и вправо исправлен.** В оригинале после движения вправо
  проверялся *левый* край (и наоборот), поэтому `ПОКА НЕ_КРАЙ СДЕЛАЙ ВПРАВО`
  выводил муравья за таблицу. Вверх и вниз работало правильно, а оригинальные
  примеры используют в циклах только `ВНИЗ`, поэтому выполняются так же;
- `*` на клетке муравья в файле — это только отметка муравья (так её пишет и
  старая программа), а не буква;
- при ошибке муравей остаётся на месте, но смотрит в сторону, куда пытался
  пойти, как в оригинале;
- `ТОГДА` и `СДЕЛАЙ` можно опускать, а `НЕ КРАЙ` принимается как `НЕ_КРАЙ`;
  `СДЕЛАЙ имя` в начале строки вызывает процедуру.

Furnica 3 сохраняет в том же формате, но старая программа понимает только
ключевые слова без диакритики (`INCEPUT`, `SFIRSIT`, `STINGA`…), таблицы
10 × 10 и невложенные блоки; совместимость в эту сторону с `furnica.exe` не
проверялась.

## Формат файлов

```text
Ant executor file
[table description]
1 10          позиция муравья: столбец, строка (с 1)
3             направление: 1 вниз, 2 влево, 3 вверх, 4 вправо
2 9 i         буквы: столбец, строка, буква
1 10 *        клетка муравья
666 666 *     конец таблицы
procedura …   программа, до конца файла
```

У таблиц другого размера, чем 10 × 10, после первой строки есть ещё строка
`[size <столбцы> <строки>]`. Старые файлы (Windows-1250 или Windows-1251)
распознаются автоматически; новые сохраняются в UTF-8 с CRLF.

## Windows 7 (32 и 64 бита)

Обычно собранный `.exe` требует Windows 10+ (требование Rust начиная с версии
1.78). Для классов с Windows 7 есть отдельная сборка, которая делается в Linux
командой:

```sh
packaging/windows7/package.sh   # результат: dist/release/furnica-<версия>-windows7-x86-portable.zip
```

Скрипт сам устанавливает Rust nightly в `.cache/` и скачивает всё нужное; из
системы ему нужны только `curl`, `7z` и 32-битный компилятор MinGW
(`mingw-w64-gcc` в Arch, `gcc-mingw-w64-i686` в Debian/Ubuntu). Архив работает
в Windows 7, 8, 10 и 11, 32- и 64-битных, без установки и без дополнительных
обновлений Windows:

- используется `msvcrt.dll` (есть в любой Windows 7), а не UCRT, которому в
  Windows 7 нужно обновление KB2999226;
- `combase.dll` из архива (3,5 КБ) перенаправляет функцию, которую новые
  библиотеки Rust ищут там, а в Windows 7 она находится в `ole32.dll`; в
  Windows 8+ он игнорируется;
- папка `soft-gl` содержит Mesa (программный OpenGL). Если у видеокарты нет
  драйвера с OpenGL 2.0 (драйвер «Standard VGA», виртуальные машины),
  программа сама перезапускается с Mesa. Медленнее, но работает. Можно
  включить принудительно: `Furnica.exe --software-gl`;
- в этой сборке нет только поддержки экранных дикторов (эта библиотека
  требует Windows 8+). В коде это функция `accessibility`, включённая по
  умолчанию в остальных сборках.

Это тот же рецепт, что и у Cangurul 3. **Внимание:** эта сборка ещё не
запускалась на настоящей Windows 7.

## macOS

Образ диска `furnica-<версия>-macos-universal.dmg` содержит `Furnica.app` —
одну программу для Mac с Apple Silicon (M1…M4) и с Intel, начиная с
macOS 10.13. Собирается только на Mac (для релизов — на macOS-раннере GitHub
Actions):

```sh
packaging/macos/package.sh   # результат: dist/release/furnica-<версия>-macos-universal.dmg
```

У приложения только ad-hoc подпись, а не сертификат Apple Developer, поэтому
Gatekeeper блокирует его при первом запуске. Откройте его правым щелчком →
*Открыть* или один раз из Терминала:

```sh
xattr -dr com.apple.quarantine /Applications/Furnica.app
```

Сочетания клавиш используют ⌘ вместо Ctrl. **Внимание:** сборка компилируется
для обоих процессоров, но ещё не запускалась на настоящем Mac.

## Структура кода

| Файл | Содержимое |
|---|---|
| `src/lang.rs` | лексер, устойчивый к ошибкам парсер и компилятор |
| `src/check.rs` | семантический анализ: предупреждения, процедуры, предложения исправлений |
| `src/vm.rs` | виртуальная машина, выполняющая по одному ходу за раз |
| `src/world.rs` | таблица, буквы, муравей и правила сдвига |
| `src/antfile.rs` | чтение и запись файлов `.ant`, старые кодировки |
| `src/table_edit.rs` | правила редактирования таблицы: перетаскивание, обмен, ввод с клавиатуры |
| `src/ant.rs` | векторный муравей (плавный поворот, шагающие лапки) |
| `src/app.rs` | графический интерфейс (egui / eframe) |
| `src/i18n.rs` | тексты интерфейса на румынском, русском и английском |
| `src/software_gl.rs` | перезапуск с программным OpenGL (Mesa) в Windows |
| `examples/` | оригинальные примеры (`conferinta`, `svi99`) и новые |
| `assets/` | шрифты, значки (`icon.py` перерисовывает их по `src/ant.rs`, включая `furnica.icns` для macOS), `banner.py` для баннера README (`python3 assets/banner.py FURNICA -o docs/assets/furnica-banner.png`) |
| `packaging/` | AppImage, `.deb` и архив для Linux, `Furnica.app` для macOS, `.msi` и архивы для Windows 10/11, архив для Windows 7 |

Оригинальная программа хранится для справки в папке `Furnica/` (игнорируется
git).

## Релизы

Версия хранится в одном месте — в `Cargo.toml` — и меняется командой
`packaging/version.sh set 3.1.0`. Релизы **автоматические**: при push в `main`
с ещё не опубликованной версией GitHub Actions собирает пакеты для всех
платформ и публикует релиз. Push с той же версией только запускает тесты.
Подробности (на румынском) — в [`docs/releasing.md`](docs/releasing.md).

## Тесты

```sh
cargo test
```

Тесты проверяют язык, формат файлов, правила сдвига, выполнение примеров (с
точным результатом оригинальных) и интерфейс: нажимают настоящие кнопки,
перетаскивают муравья и буквы и печатают на таблице — без окна. С
`FURNICA_SHOTS=<папка> cargo test` они также сохраняют снимки экрана (снимки в
`docs/assets/` сделаны так).
